Install and use

Python training environment

Install the v0.1.0 wheel, verify four complete trajectories, then connect your own policy. Choose the wheel that matches your Python version.

PlatformPython
Windows x86_64CPython 3.14
Linux x86_64 (glibc ≥ 2.35)CPython 3.12
Open v0.1.0 downloads
Install and run the full verification

Download the wheel and sts-verification-0.1.0.zip into a new directory, then run these commands there:

Windows / PowerShell

py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\sts_learning_bridge-0.1.0-cp314-cp314-win_amd64.whl
.\.venv\Scripts\python.exe -m zipfile -e sts-verification-0.1.0.zip .
.\.venv\Scripts\python.exe sts-verification/verify.py --output verification-results

Linux

python3.12 -m venv .venv
.venv/bin/python -m pip install ./sts_learning_bridge-0.1.0-cp312-cp312-manylinux_2_35_x86_64.whl
.venv/bin/python -m zipfile -e sts-verification-0.1.0.zip .
.venv/bin/python sts-verification/verify.py --output verification-results

The verifier executes recorded decisions for all four characters from Neow through a Heart victory and saves results in verification-results. It checks actual choose/step calls, public state, rewards, recovery and terminal results without starting the original game.

Connect a policy

Implement choose(batch, schema) to return one legal candidate ordinal per current decision, then run the loop included in the verification bundle:

python sts-verification/policy_loop.py --policy my_policy:choose --seeds 42 43 --character silent

Use the virtual environment’s interpreter created above. Put model loading and candidate scoring in my_policy.py beside policy_loop.py or in another importable module.

Let a language model play

The offline bundle includes source matching this interface and plugin. On Windows, prepare Rust, Node.js 22 or newer, and PowerShell 7. Extract the source and run from its SpireSim directory:

Download matching source →
./scripts/run-play.ps1 build
npm --prefix tools/presentation ci
npm --prefix tools/run_play ci
npm --prefix tools/dsh_player ci
npm --prefix tools/dsh_player run build:client

In DeepSeek Harness 0.2.1-rc.2, add tools/dsh_player through the Plugins page and configure your model and API key. Start a new chat with the source directory as its workspace and select the “杀戮尖塔 A20H · 公开信息” public-information preset.
