# 策略研究边界

目标是提高整局决策质量：过渡战力、长期构筑、路线机会与血量、金币、药水的使用。
尚无通过自然 A20H 质量验收的自主策略。实现入口见 [RUNBOOK](../RUNBOOK.md)。

## 职责

游戏核心拥有状态、合法动作和结算。搜索提出经过真实转换检查的打法；本地网络可以学习
选择或估值。研究调用方负责任务定义、数据划分和成本记录，不复制游戏机制。

模型候选与任务基线共用公开资源候选准入规则。地图和选牌页把丢药延后到领取药水等相关
页面；满药槽的奖励页和商店继续保留换药选择。手动玩法保留核心全部合法动作。
完整选择监督与模型范围检查针对准入后的整个模型候选面，标签不参与过滤。
学习入口的地图表示下一条路线的提交，关闭地图不进入该候选面；任务控制器仍可关闭
浏览中的地图，回到待领取奖励。两者使用不同的导航职责，不能用关闭操作代表路线取舍。

固定战斗策略实验可显式启用 `strategic_navigation`。程序处理单一合法选项，以及只有
选牌入口和离开按钮的奖励菜单；满槽换药、遗物和钥匙取舍等混合菜单仍由策略选择。
程序动作经原生接口实际结算，在训练和评测中均于模型调用前分流，不作为 actor 样本。
奖励跳过记忆复用控制器的提交逻辑，随环境和槽位 checkpoint 保存；未完成的战斗宏不
提交该记忆。仅含程序动作的终局延续可以关闭先前已有模型样本的轨迹，不伪造网络选择。
此分工缩小学习任务，不提供构筑建议，也不证明策略质量。

本项目可以直接指定 Codex 的判断与示范为监督来源，记录作者、当时可见信息与采用理由；
不以另一次人工审核或更高级教师作为使用这些标签的前置条件。需要纠正的标签由同一研究流程
复查、修订并保留版本。模仿这个教师不要求证明其动作最优，也不产生无偏最优标签。
本地训练与推理不需要每一步调用外部 LLM 或教师服务。

搜索和学习可以独立研究。现有算法与模型的存在不要求复用它们；是否结合取决于各自贡献
和整体打法的对照结果。共享执行接口不构成策略有效性的证明。

## 信息和目标

- NoSL 使用当前可见信息及允许的记忆，隐藏牌序不能通过模拟器输入泄漏。
- Seed-SL 可以记录明确来源的回溯与分支试探；固定 oracle 评测单独报告。
- 战斗结果包含生死、血量、药水与遗物计数等资源。保留资源的价值还取决于后续路线，
  不能用一条固定 HP 换药比例替代整局判断。
- 商店库存与可买动作分别完整可见；多选保留实例与顺序，不预先展开全部组合。

公开事实、策略判断和后继规划分别验收。学习输入保留卡牌实例数值，另提供当前牌库的类型、
持久费用分布，以及已核对的攻击次数、条件和力量生效方式。分布只统计已经拥有的牌，
候选、商店库存、奖励和升级预览分别表示；这些事实不构成卡组战力、启动概率或战斗上限估计。
公开牌库另汇总按核心规则可升级的实例数及其中 Basic 牌数。卡牌与升级预览保留已核对的
直接自损、抽牌请求和能量请求数值，能量同时保留触发时机；自损附防护及触发属性。
这些是牌自身的请求，实际结算仍受存活、防止效果、抽牌限制与容量等条件影响。
未核对、可变或有条件的请求保持缺失，不用零值或固定值代替。
Warcry 的抽牌请求与随后手牌置顶数量分别保留；四张铁甲造状态牌直接读取核心的
状态牌身份、数量、目的牌堆、排队顺序及初始升级和虚无属性。生成请求不加入当前牌库，
手牌溢出、生成修正及战斗结束清队列仍由运行时结算。牌库的 Strike 标签总数只统计已拥有
实例，复用战斗的标签成员规则；它不是战斗中仍未消耗的数量或最终伤害预测。
公开牌库还按已核对的核心规则汇总力量来源牌的数量，分别保留即时、意图条件、临时与
每回合触发，并分别统计部署后提供消耗抽牌、消耗格挡的能力牌数量。计数只描述已拥有
实例；牌自身另保留每次消耗事件的抽牌或格挡请求。这些事实不说明能力已经部署、
力量已经获得或牌组已形成可用引擎；未核对的来源与遗物配合仍需分别处理。
选牌页继续保留所属的整批公开待领取奖励，领取后按当前集合重新观察。

图输入为每个 token 标明归属：零表示当前公开观察，正数是本行某个候选及其预览或后继。
归属编号只约束消息与聚合，不作为数值特征。候选读取当前观察和自己的内容；当前观察
不接收候选的反向消息，也不汇总预览。卡组、地图、商店库存和待领取奖励仍是公开观察。
策略分别使用观察汇总及候选的局部汇总；估值头只读取当前观察。分层类型头用集合最大值
汇总同类候选，重复目标不改变汇总；新增不同目标仍可改变该类型的判断。这个边界保证
信息归属，不能代替条件取舍的训练和自然策略验收。
直接评分可显式使用 `candidate-attention` 观察汇总：每个候选以自己的表示查询同一行当前
观察 token，将所得加权汇总与原全局平均汇总一起用于评分。候选和预览不能作为查询池中的
观察，当前观察与估值头仍不接收候选信息。默认保持 `mean`，汇总配置进入权重合同，
不能跨方式恢复初始化；这个学习读取机制不提供人工相关性标签或策略规则。
分层评分另可显式选择 `candidate-score-max`：先对每个真实候选及当前观察评分，再取同类
最高分。它避免先逐坐标混合同类候选再评分时产生没有真实候选对应的表示。配置进入模型
合同，原 `vector-max` 权重保持原解释；跨这两种聚合方式不能静默恢复或冻结精修。
抓牌与 Boss 遗物候选的列表编号只用于执行和审计，不进入学习数值特征；改变候选排列
不改变其策略内容。战斗中可见牌堆顺序等有机制含义的位置继续保留，不能统一抹去位置。

当前 scoped 采用动作监督只训练抓牌和营火的局部选择。幕层、公开 Boss、地图、资源和最近战斗摘要
虽已进入输入，出现这些字段不代表模型已经学会相应关系；其他决策点仍由公开基线处理。
地图的紧凑准备读数复用公开连线 owner：按同一路径上营火和商店的四种有无组合，
分别保留首次精英的最早距离，并区分公开 Boss/胜利端点与未公开后继。共享读数从
当前房间的下一节点开始；路线候选从自己的目标节点开始。分别可达的营火和商店
不合成为同路机会，问号结果与未来飞行保持未知。读数没有给出战损、卡组准备程度
或选择建议；原教学的普通战走廊也不因增加字段就覆盖自然精英路线。
已核对的机制关系由核心提供，卡组缺口、条件下的边际价值和取舍由策略负责。
训练集拟合不能证明对新的卡组、遭遇或幕层具备决策能力。

完整决策模型的 `model_sites` 只声明已有非 Unknown 训练监督的站点。真实接入还要求训练
拟合通过，并由同一教师在监督协议的 `applicability` 中明确使用范围；缺少声明的权重仍可
离线研究，不能直接装载跑局。声明按站点列出幕、楼层与进阶范围，以及核心 schema 中的
卡牌、遗物、药水、机制角色、机制事实编码覆盖、动作类型、目标、角色和 Boss 类型域。
检查覆盖整个公开输入和候选内容，不裁掉范围外候选。
可选 `observation_categorical_domains` 按核心 token 类型，对共享 scope 0 观测的直接类别
字段进一步收窄。例如 `Card.CardId` 声明已拥有库存的身份域，与奖励和动作的身份域分开；
见过某张候选牌不代表已验证含它的牌组。此限制与全局类别域同时生效，不把创建请求当成
库存；未声明时保留原全局域解释。范围仍由教师显式判断，字段出现次数不自动证明能力。
范围外或必要事实不可观察时，整批选择在评分、采用和基线接管前停止，保存公开输入、
原因及精确 endpoint。
范围停止同时可采集采用前的数值观察，选项编号为 null、采用状态为 false。指定教师可用
显式 `public_observation` 标签依据判断该完整候选面，保留来源、原始采用状态和 seed 分区。
这类监督不要求先执行所选动作，也不提供结局或战斗胜线标签；基线模仿仍只使用已采用动作。
使用范围随模型来源和控制器身份绑定；训练样本出现某字段不自动扩大声明范围。
这是有界诊断的执行条件，既不证明域内任意牌组组合已学会，也不宣称自然 A20H 质量。

完整决策拟合可另选 `field-membership` 树分类后端。它从当前观察与候选自己的归属分别读取
命名字段，统计类型和类别数量，以及各类型数值字段的出现次数、和、最小值与最大值。
出现次数区分缺失和已给零值；训练词表固定，推理忽略未收录的列。默认读法丢弃图关系和
同一实体各字段之间的连接。显式 `owned-card-upgrade-statistics-v1` 保留原字段，并按已拥有
`Card` token 自己唯一明确的 `CardId` 汇总牌数、可升级状态和升级次数；候选、奖励牌和升级
预览不进入这项库存汇总。它只保留直接身份与升级字段的连接，不加入卡牌效果表、跨实体
图连接或策略规则。显式 `owned-card-local-choice-statistics-v1` 在此基础上只移除共享 scope 0
的 `OfferedCard` 目录，保留当前库存和每个候选自身的完整事实，避免其他候选目录混进当前
候选的特征。词表也拒绝共享目录字段。它是逐项评分表示，不能据此覆盖联合奖励或商店的
多步规划。读法进入训练、装载和行为身份合同，旧模型继续按原合同解释。
另可采用 `owned-card-class-local-choice-statistics-v1`，在局部读法上按已拥有牌的明确
`CardType` 与是否为 `Basic` 稀有度分组，保留组内牌数及直接数值字段的出现次数、和、
最小值与最大值。分组属性和数值来自同一牌；奖励、候选与预览不进入这些库存分组。
它保留基础攻击等组别与数值的连接，不提供卡牌价值、回合产出或跨牌组合规则。这些读法
都不替代启动、费用效能或战斗强度分析。监督保留完整可采用集合，并允许教师显式声明
其中非空的优先子集；训练选择目标取优先子集，未声明时取可采用集合。最终仍从全部合法
候选取最高分；Unknown 行不提供正例或负例。默认目标为二分类；显式 `lambdarank` 把每个
完整合法面作为一组，按选择目标成员为 1、其余为 0 学习组内排序。次优但可采用候选的
可接受性单独报告，不能当作推荐已学会。分数不表示完整可采用集合的概率；拟合与装载
合同分别记录并核对选择目标、优先行数和推荐间隔。
排序可显式采用 `preferred-acceptable-v1` 分级：选择目标为 2，次优但可采用选项为 1，
集合外选项为 0，使用线性等级收益。未声明优先子集时全部可采用选项为 2。
默认 `choice-target-v1` 和旧合同保留原目标；分级进入合同与行为身份，冻结核验继承原模式。
采用仍要求原来的完整选择与推荐间隔，分级训练不证明较低名次已全部排对。
评估另列显式优先子集的命中、次优可采用选择与间隔，以及可采用集合回退和 Unknown 的
行数。未声明优先子集的可采用命中，不能计作已学会教师的额外推荐。
普通拟合与冻结核验都在摘要的 `ignored_columns` 中分别列出训练、评估时被固定词表忽略的
字段。该读数说明实际读取边界，不扩大词表，也不证明被忽略的事实对决策无关。
摘要的 `evaluation_support` 按冻结数值输入区分新观察、已见观察但有新候选，以及全部候选
输入已见的开发记录，同时报告不同观察数量和当前读法保留的字段是否也已见；后者含
词表忽略的字段，但不代表完整原生图。仅比较非 Unknown 的
训练监督；被忽略的事实变化可能留下相同数值投影。各组可接受性与推荐命中分开报告，
这些支持度信息不参与训练、停止、seed 分区或采用门禁，也不证明相应策略已经学会。
`reference_role` 区分当前训练监督分区与零更新的冻结核验分区；后者的输入比较不表示
来源模型曾在这些局面上优化过。
树权重与字段词表使用独立合同保存，沿同一装载、拟合与范围检查进入控制器。运行时没有
教师标签或外部模型调用；接口检查与局部拟合也不代表已掌握完整构筑、商店或多步规划。

`strategic_guide` 提供独立的教师条件规则原型，由同一 `StrategicRunController` 的显式
`card_reward_guide` 参数接入，默认不启用。规则读取核心的公开数值和配对 audit 中的身份，
不读取逐行答案、来源 seed 或教师理由。当前只有第一幕铁甲起始牌库的首次攻击补充关系；
血量至少一半时优先已覆盖的高效攻击，至多四分之一时优先幽灵铠甲而非御血术、莽撞冲锋
和跳过。比例是 Codex 指定的有界策略默认，不是游戏机制或最优阈值。
牌库新增牌、其他遗物、中间血量及相互未比较的攻击仍可使整批选择保持 Unknown。
待领取多个抓牌奖励或遗物的联合准备也保持未决。

每条规则产生有理由的两两偏好，完整菜单的全部候选参与偏好图。新候选保留为未决竞争项；
冲突、必要事实缺失或多个未被压过的候选时，在任何 `choose` 前停止同批采用。
结果和收据使用 `guide` owner，与模型采用及公开基线分开。当前原型还没有模型处理剩余
比较；不能与抓牌模型同时拥有该站点，也不改变营火模型的范围检查。
规则与 schema 进入行为身份，恢复时须提供同一规则。覆盖未决与策略失误分别诊断；
通过条件测试或一段新前缀不表示它可以承担完整跑局。

同一入口的 `--frozen-field-model` 可将已通过装载核验的树，对新的显式教师语料与适用范围
重新核验。权重和词表原字节保留，零更新；新目录绑定来源合同、摘要、行为身份和祖先 seed。
新训练监督的每条完整选择和要求的 margin 都须通过；失败保存 `frozen_unfit`，不能装载。
CLI 沿用来源读法、目标和 margin，拒绝优化器参数。开发评估在核验后进行，不参与训练拟合
判定；旧评估 seed 仍是开发数据。扩大后的合同只支持有界诊断，不能据此宣称新组合已覆盖。

商店与奖励集合按真实动作逐步结算、重新生成观察。补货员的新货、随机变牌的结果在转换后
才可用；当前快照不提供它们的隐藏未来值。多步预算、先观察多个奖励再采用、随机后继的
条件策略，需要有相应记忆或规划及完整序列监督；单步采用动作标签不提供这些后果。
研究用 Node-SL 可以试探精确 checkpoint，须按其权限报告。当前 scoped 跑局的固定整场战斗
Oracle 与公开战略模型分别报告，不据此宣称 NoSL 战斗、SL 知识管理或自然 A20H 已完成。

## 信息约束下的战斗规划

以下约束用于设计和验收使用有限信息的搜索，不表示现存 Oracle 求解器已经具备这些能力。

真实战斗状态保留精确牌序、实例和 RNG，由模拟器结算。当前观察说明这一步可见什么；
行动与观察历史提供可记忆的证据。搜索使用的知识由两者共同决定，不能仅凭一个隐藏了
牌序的快照代表全部已知信息，也不能通过候选后继的优劣偷偷使用尚未取得的隐藏信息。

牌序知识允许局部成立：例如已知牌顶、已知相对顺序，以及位置未知的剩余牌。Headbutt
放回的牌可以确定下一抽，而不需要知道整个抽牌堆。抽牌消耗已知位置并揭示实际结果；
洗牌按影响范围和已有证据更新顺序知识，无法继续确定的部分降为未知，牌的组成与其他
未受影响的事实仍然保留。随机插入可能使确切位置未知，同时保留旧牌之间的相对顺序。
不能把“遇到随机”统一处理成清空记忆。

SL 观察需要绑定试探来源、动作经过和成立条件。原分支见过的牌序，不自动适用于改变
洗牌输入或相关 RNG 消耗的分支；确定的置顶、移除等变化则可据机制更新知识。相同 seed
或相同当前画面都不是可复用证据的充分条件。适用性尚未确立时记录 Unknown，不能从目标
分支的隐藏状态补出答案。试探记录与已提交行动继续分别保存。

搜索可以跨抽牌、洗牌和回合向后规划。在拥有相同信息的可能局面中，选择必须遵循同一
决策规则；只有新观察或允许的 SL 证据将它们区分后，后续选择才能不同。抽牌不一定揭示
新信息，内部 RNG 消耗也不一定产生新观察，二者都不能机械地充当决策树分叉条件。
分别求出各个隐藏世界的最好路线再平均，只能描述先知条件下的结果，不能代替可执行策略。

相似动作可以在有限预算内共享探索机会，不要求先证明所有长远结果相同。保留的代表仍
携带真实状态与 RNG；近似分组不得成为精确状态相等、完整覆盖或其他分支无解的证据。
未探索的排列可以舍弃，不要求保存所有延期分支；有明确牌序控制依据时再有针对性地展开。

## 评测

局部偏好与完整决策监督分别保存。只知道甲优于乙，不能保证甲优于未比较的丙；
局部比较全部学会，也不能认证从完整合法候选中取最高分的策略。完整决策示范应直接给出
教师当时愿意采用的一项或多项动作；整行无法决定时暂不提供决策目标，不把未比较候选
默认为错误，也不让训练标签在推理时替模型筛选答案。完整决策的 `preferred` 必须是已知
`acceptable` 的非空子集，v2 标签显式保存该字段；原 v1 保持可采用集合语义。训练与冻结
核验要求完整动作命中选择目标，并满足其相对全部其他候选的间隔。报告分别保留可接受性
和推荐命中；装载不能仅凭可接受性通过就放行未达到推荐目标的权重。开发标签仍不参与停止。
两条离线路径的来源合同和完整动作拟合入口见 [learning](../../learning/README.md#teacher-authority-and-decision-supervision)。

完整决策拟合可显式选用 `family-target`：按核心提供的 `ActionKind` 分组，分别监督动作类型
和同类目标。默认仍为 `flat`。分层损失使用可采用类型集合及其各自的可采用目标集合，
Unknown 行不监督任一层；推理保留完整合法候选，通过类型分数加组内相对目标分数取最大值。
训练停止仍检查完整动作，报告分别保留完整动作、类型和类型正确时的目标选择结果。
普通随机采样器仍对合成候选分数采样，不具有独立的两层概率语义；这个离线选择不自动进入跑局。

同一训练 owner 可显式选择 `--supervision-level action-family`，只从完整动作标签推导
原生类型集合，不监督同类目标。Unknown 与允许所有已提供类型的行，不进入类型损失和
有信息命中率的分母。输入仍是完整公开图与候选面，停止只检查训练类型及其间隔。
该任务要求新的分层初始化，输出独立的 `sts-scoped-family-clone-v1` 合同及原生类型编码，
不输出采用动作编号；完整玩家装载和精修入口拒绝该合同。类型命中不能证明知道拿哪张牌，
也不能代替卡组条件下的候选价值判断。默认完整动作监督保持原语义。

已有分层模型可通过 `--frozen-family-model` 只更新目标排序头。来源权重、合同和摘要绑定，
图表示与类型分数路径保持固定，并在训练后检查权重完全一致。已有类型判断不能满足训练
目标和间隔时直接拒绝这种精修；目标训练不能修好错误类型，也不自动解除冻结。
初始化来源及祖先的训练、评测 seed 继续保留；已见过的局面仍按开发证据报告。

类型判断也需修正时，`--frozen-encoder-model` 固定图表示与估值头，同时拟合类型和目标两个
打分头。它与上述仅精修目标的入口互斥，沿用相同的来源、seed 和完整动作停止检查。
固定表示不保证旧选择正确，也不能增加表示容量；采用前仍需核对旧判断与新的公开局面。

固定表示难以学会新增条件时，可显式使用 `--initial-model` 从已核验的同架构权重初始化，
共同训练图表示与策略头。它与两个冻结模式互斥，保留来源及祖先的 seed 分区，
不修改来源模型；采用前重新检查既有判断，不能声称类型或表示路径仍然固定。

训练集拟合诊断先检查模型能否学会已经提供的监督。充分拟合之后，再检查新局面的实际
选择与条件变化；短暂训练后仍有训练错误，不能直接归因于泛化、表示不足或架构上限。
拟合诊断和开发阶段已经查看过的局面都不冒充独立验收。
不同牌组恰好对应不同血量时，拟合成功也可能只学到牌组区别。固定其他输入、只改变相关
公开条件的构造检查用于定位这种混淆；训练使用的构造对照单独声明来源和改动，不冒充
自然采集或新局面的迁移效果。

先说明要检查的能力、初始条件与停止条件。构造例子可以隔离机制，自然前序检验真实资源
约束；两类证据分别标记。数据采集、调参和最终评测使用分开的 seed 集合。

检查完整战斗或路线、资源损失与实际行为，保留失败、截断和未完成案例。高胜率、平均楼层
或较小的估值误差都不能单独证明打法合理。局部反事实比较也不能自动成为最优动作标签。

当前 `run-play deck-lab` 使用玩家正在使用的整场求解器，对当前资源进行同幕遭遇或显式 Heart
试验。报告保留确切根、已重放胜线与资源、工作和停止原因；一条失败线路不代表全部线路失败。
情景种子改变完整诊断 RNG，不是仅更换首手牌序。固定完整状态的见证比例只描述
这些情景中的搜索可达性，不能当作未知牌序下公开玩家的胜率，也不直接成为训练标签。
按当前血量和满血两种条件试验时，应把资源债与卡组战斗能力分开解释。

真实战损与决策质量分别报告。前者是实际发生的事实；后者是在决策时信息、任务目标和
明确的未知量分布下，对可执行策略的估计。一次坏抽牌不能单独证明原决定差，但已可预见
的坏抽牌风险仍须计入。减少结果噪声不能修改真实洗牌、删除坏结果或免除冒险的代价。

未知量取样只在已有证据允许的范围内进行，后继必须与行动和新增观察一致。跨候选配对
随机样本可以用于减小估计波动，但须保持各候选自己的转换分布；同一个 seed 不保证两条
动作路径经历相同的随机事件。记录取样假设、样本量和计算预算，保留死亡风险、战损及
具体资源结果，不能把有限样本上的最佳结果当作保证。SL 试探后的判断与试探前的判断
具有不同信息条件，不能用试探后才获得的知识断言试探前本该怎样选择。

训练数据保留实际观察、合法选择、采用动作、后继和生产者身份。搜索预算耗尽是 Unknown；
记录不能把试探路径伪装成已提交轨迹。Java 一致性另按 [TESTING](../TESTING.md) 核验。
