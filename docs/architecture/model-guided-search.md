# 本地学习与搜索组件

这是当前实现的索引，不指定下一代搜索算法。运行实验见
[实验入口](../../tools/guided_search/README.md)。

## 现有职责

| 组件 | 当前作用 |
| --- | --- |
| `sts_guided_search::combat` | 共享模拟器上的真实转换、合法选择和胜线重放 |
| `observation`、`entities` | 战斗语义观察与变长数值编码 |
| `natural` | 新建自然前序示范、构造战斗和连续段的执行 owner |
| `path_search` / `objective` | 固定资源条件与探索顺序、可续接路径队列、冻结 prior 接口与完整胜线回放；相对 prior 顺序可暂存深度受限边 |
| `path_search::linear` / `path_learning.py` | 同源数值输入、Rust 冻结线性 prior 与 Python 完整路线目标拟合；显式实验入口 |
| `path_search::routes` | 从显式完整胜线重建当前搜索选择与条件账本；共用动作准入，逐个真实后继与独立回放核对 |
| `distance_search` / `distance_learning.py` | 显式后继局面距离试验；真实转换、独立回放、事实区间与冻结批次预测分开，详见[使用合同](../../tools/guided_search/README.md#后继局面的距离启发试验) |
| `tree`、`guidance` | 现存带权树搜索试验及进程内批次指导 |
| `local`、`segment_learning` | 本地策略采样、反馈和连续段接口 |
| Python bridge | 批次传输与 NumPy；游戏状态和合法性仍由 Rust 负责 |

这些组件被现有本地实验调用，保留不表示算法已通过质量评测。外部 LLM 请求、文本回复
解析和 provider 传输不属于本地学习依赖。

## 研究边界

当前树搜索可能在首条已验证胜线后结束；它的指导权重、叶估值和预算会影响找到的路径。
固定策略续打能测量该策略的后果，不能给其他策略提供最优性结论。

完整路线导出保存根状态、资源条件、真实输入、逐步选项、选择及完整终局资源。组合选牌
按当前 typed 来源还原有序选择，不遍历排列，也不按牌名合并实例。准入和概率分组与
`PathSearch` 共用实现；旧搜索只可提供显式打法证据，不提供树、评分或最优动作标签。
结构化证据与模型输入分开。线性 prior 的数值输入由同一 Rust encoder 在导出和运行时
生成，附带目标及原瓶关系；路线标签、终局、源文件身份、输入序号和剩余距离不进入
encoder。整场与来源组不能被逐行拆散后当作独立样本或测试集。组件已接通不等于指导
质量或计算节省已通过广泛评测。

重新研究搜索时，以共享模拟器和合法动作为可依赖的基础；是否沿用现有树、评分或结果应由
明确实验决定。当前没有证据要求继续扩展某一算法，也没有合格的自动搜索教师。

## 指导信号与验收目标

以下三个量应保持不同语义，不能因为都能输出一个数字就互相替代：

| 量 | 所回答的问题 | 证据限制 |
| --- | --- | --- |
| 给定资源条件的剩余操作距离 | 还需多少真实输入才能到达一个合格终局 | 已找到路线的长度通常只是上界；最短距离需要额外覆盖证据 |
| 完整打法的物化资源 | 这条实际路线结束后保留了什么 | 一条已知打法不代表该状态的最佳后续；更多操作可能换来更好的资源 |
| 找到合格／更好方案的计算量 | 指定搜索器与模型花了多少工作 | 依赖队列、已有证据、预算及实现，不能直接作为状态固有难度标签 |

准确的距离启发可以帮助搜索；在确定转换、正代价真实输入和有限虚拟组装的前提下，
精确目标距离能指引选择沿距离下降的后继。但这样的精确信息本身已经包含很强的求解能力。
神经网络的近似距离、已见胜线长度、有限覆盖下界都不自动具有这种性质。
距离预测误差降低也不单独证明完整资源结果或搜索效率改善。

最低终局HP／保留原瓶查询定义的是合格集合，不是在集合内最大化资源。短路线仍可能
多损血；相同长度也可能产生不同资源。原有资源前沿负责保留实际备选，操作数不替代
药水的战略价值。提高最低HP会改变查询，不等于给现有队列无成本增加一项偏好。

学习目标可以帮助分配探索，但需说明它在何种信息、来源和条件下成立。已核验短程后继
及其终局事实可以直接使用；未检查的后续保持Unknown。完整路线之间的资源优劣可作为
这些已观察打法的比较证据，不能把它升级为两个中间状态所有可能后续的最优排序。
训练后应从完整根状态比较实际资源和总成本，包括准备、推演、模型推理与回放。

相关原始研究区分了解的路径代价与搜索代价：
[LevinTS](https://arxiv.org/abs/1811.10928) 的界同时依赖路线长度与指导概率；
[PHS](https://doi.org/10.1609/aaai.v35i14.17469) 将策略与启发结合，分析搜索损失。
它们的理论前提、训练替代目标和实验结果须分别理解，不能把公式直接套到本仓库的
计费、虚拟选择、资源前沿或有限预算上。现有 `path_search` 已有 prior 和整条路线代价
目标；“加入prior”本身不是新的有效性证据。固定RNG局部搜索也不因此获得NoSL资格。

## 评估

评价搜索应保留完成的打法、剩余血量、药水消耗、计算成本、失败和未完成范围；不能只报告
是否击杀或一组固定 seed 的命中数。完整打法的资源质量与状态估值误差分别检验。

信息条件需要显式声明。固定 oracle 的局部可达性、Seed-SL 的反复试探和 NoSL 下只能依据
可见信息的决策，回答的是不同问题。随机性评测要预先划分 seed，报告分布和较差结果。
