## Why this case matters

### A nominal engine can be encounter-negative

The deck contains six Powers and several apparent synergies, but the proposed Awakened One line
admits only Barricade. Inflame+, Combust, Combust+, Evolve+ and Dark Embrace are treated as cards
that must remain unused because their local benefit does not justify empowering the Boss.

This is a concrete counterexample to both of these weak policies:

- “the deck contains an engine, therefore start every engine component”;
- “a highly rated card should be played whenever legal”.

### Deck evaluation must include suppression

Capability assessment normally asks what the deck *can* do. This case adds a second question:
which otherwise useful capabilities must be withheld in this encounter, and can the remaining
subdeck still win? A proposal surface therefore needs negative admission evidence, not only role
presence.

### Reload policy is part of the state contract

The author carefully separates the No-SL source run from a relaxed draw-order thought experiment,
while still forbidding arbitrary RNG manipulation. Those are different observation/action rights;
they must not share an unlabeled outcome.

## Verification boundary

The thread does **not** include a replay-exact combat root or the full winning trace. The asserted
first-step uniqueness and eventual win remain expert testimony. The screenshots prove the deck
composition, not the solution.

Engineering use is therefore limited to:

- a reviewable encounter-conditioned Power-admission hypothesis;
- a regression question for a future exact Awakened One case;
- a counterexample to static card scores and unconditional engine activation.

It must not become a forced action, a teacher label, or proof that the shown line wins.
